# VJW Luxe — Reconstructed Frontend

This project recreates the visible structure and content style of the public VJW Luxe website.

## Technologies
- HTML5
- CSS3
- TypeScript
- React
- Vite
- Lucide React icons

## Run locally

1. Install Node.js.
2. Open the project folder in a terminal.
3. Run `npm install`.
4. Run `npm run dev`.
5. Open the local URL shown by Vite.

## Important note

This is a clean reconstruction based on the public rendered page. It is not an extraction of Lovable's private source repository or backend code.

## Main sections
- Navigation and shopping bag indicator
- Autumn Collection hero
- Shop by Category
- VJW Luxe story
- Lifetime Care / Ethical Sourcing / Signed & Numbered promises
- Website & App callout
- Footer and contact link
